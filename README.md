# TO ETERNITY AND BEYOND
*A game made for Maria.*

Короткая личная романтическая визуальная новелла на **Godot 4.x**.
1–2 часа истории, которая постепенно из «загадочной игры» превращается в признание.

> Game Design Document: **[docs/GDD.md](docs/GDD.md)** — сюжет, главы, выборы, загадки, секреты, весь план.

## Быстрый старт (macOS)

1. Скачай **Godot 4.3+** (стандартная версия, не .NET): <https://godotengine.org/download>
2. Открой Godot → **Import** → выбери папку этого проекта (файл `project.godot`).
3. Нажми **F5** (Run Project).

Или из терминала:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

Проверка целостности данных (сценарии/выборы/ачивки/локали):

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/validate_data.gd
```

## Как редактировать историю (без кода)

Вся история — **JSON**, никаких сценариев внутри скриптов:

| Файл | Что это |
|---|---|
| `data/dialogue/chapter_XX.json` | Сценарий главы: реплики, фоны, музыка, выборы, фрагменты |
| `data/choices/choices.json` | Тексты вариантов выборов и их последствия |
| `data/characters.json` | Таблички имён и цвета персонажей |
| `data/memories/memories.json` | Фотографии-воспоминания (даты, подписи) |
| `data/achievements/achievements.json` | Достижения |
| `data/locales/ru.json` / `en.json` | Строки интерфейса |
| **`data/custom/about.json`** | ★ Имена, финальный вопрос, посвящение |
| **`data/custom/song.json`** | ★ Твоя песня: трек + таймкоды + перевод |
| **`data/custom/letters.json`** | ★ Письма, расшифровка, финальное сообщение |

Полный справочник формата: **[docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)**.

**Личные ассеты просто кладутся по финальным путям** — код не трогается:

```
assets/photos/photo_01.jpg …   — настоящие фотографии
assets/music/song.ogg          — ваша песня (Глава 5)
assets/music/chapter1.ogg …    — фоновая музыка
assets/sounds/click.ogg …      — звуки
assets/fonts/JetBrainsMono-Regular.ttf — шрифты (подхватятся сами)
```

Пока файлов нет, игра работает с плейсхолдерами (в логе — мягкие предупреждения, не ошибки).

## Что уже в игре (Фазы 2–6)

- **История глав 0–4 целиком**: пролог («Привет, Мария…»), знакомство с хранителем,
  три воспоминания с Мирой (порядок выбираешь ты), письмо-шифр с настоящей разгадкой
  (числа строятся из твоей фразы — правь `letters.json`, шифр не сломается), глава писем
  под дождём. 134 реплики на русском с английскими дублями, ветки выборов сходятся обратно.
- **Загадки (5 готово, 1 — с главой 6)**: тумблеры проектора (туториал-вальс),
  «Звёздный каталог» (шифр строится из твоей фразы), хронология трёх вечеров,
  скрытое имя в письме (светящиеся буквы — слово правится в `letters.json`),
  сборка сообщения из 7 фрагментов (механика готова, входит в главу 6).
- **Мини-игры (3)**: «Найди пары» (после 6 промахов Старик «случайно» подсвечивает
  пару; ≤5 промахов — PERFECT PAIRS), фото-пазл 3×3 (источник — `assets/photos/puzzle_photo.jpg`),
  «Пластинка заела» (повтори мелодию; ноты — тона, заменю на твою песню в главе 5).
- **Ачивки в игре**: FIRST STEP, FIRST MEMORY, PUZZLE SOLVED, PERFECT PAIRS.

## Секреты (все 6 работают)

1. **Секретная комната/фото** — чужое фото в главе 2 → Галерея → СЕКРЕТЫ.
2. **Слово в меню** — набери её имя на клавиатуре в главном меню → скрытое письмо + WHISPER.
3. **Сцена молчания** — в главе 4 под дождём не нажимай ничего 30 секунд → PATIENT HEART.
4. **Луна** — на улице/крыше кликни по луне 7 раз → NIGHT OWL.
5. **P.S.** — после титров подожди на чёрном экране 10 секунд.
6. Счётчик секретов — в Галерее.

**Текущий релиз: [v1.0.0](https://github.com/ketchuneziko/game-for-beloved/releases/tag/v1.0.0)** — тег на полном прохождении всех 12 фаз.

## Сборка релиза (на твоём Mac)

```bash
# разово: поставь Godot 4.3 + export templates (см. docs/BUILD.md, 5 минут)
bash scripts/build/build_mac.sh release   # соберёт macOS .app + Windows .exe в exports/
```

- `.app` — universal (Intel + Apple Silicon), ad-hoc подпись, инструкция для
  Gatekeeper в файле **«КАК ОТКРЫТЬ.txt»** (кладётся рядом и уезжает Марии в zip).
- Windows `.exe` — одиночный файл, собирается с Mac без доп. инструментов.
- Android — пресет готов, требует Android SDK (по желанию, см. docs/BUILD.md §5).
- **Или вообще без своего Mac:** Actions → release-builds → Run workflow —
  GitHub соберёт всё сам (см. docs/BUILD.md).

## Финал (без спойлеров в коде)

Глава 7 и концовка собираются из `data/custom/about.json`: её имя в созвездии,
сам вопрос, обе кнопки «ДА», строки «Я люблю тебя…» и посвящение в титрах.
После титров — секрет на чёрном экране (жди 10 секунд). Дальше — рассветное
главное меню с пунктом «ЕЩЁ РАЗ ♥».

## Как положить СВОЮ песню (Глава 5)

1. Положи трек: `assets/music/song.ogg` (или `.wav`).
2. Открой `data/custom/song.json`: впиши путь в `track`, строки оригинала в `text`,
   русский перевод в `translation`, и тайминги в секундах в `time` (по возрастанию).
3. Всё. Сцена сама подхватит: строки появляются строго по позиции аудио (без таймеров),
   с компенсацией латентности микшера. Дослушивание до конца — ачивка LISTENER.
   Пропуск в углу существует, но ачивки не даёт.

Плейсхолдер-песня уже внутри (82 сек, мягкое фортепиано, 10 строк с переводом) —
можно перегенерировать: `python3 tools/make_placeholder_song.py`.

- **Save/Load**: 5 слотов + autosave + quick (F5/⌘S, F9/⌘L) — с превью-скриншотом,
  названием главы, временем игры, фрагментами и датой; удаление слотов; быстрое меню
  в игре и пауза (Esc) работают с любым слотом.
- **Выбор глав**: открытые главы кликабельны (с датой из JSON), непройденные — с замком;
`chapter_end` автоматически открывает следующую главу.
- **Стиль — pixel art**: фоны 320×180 с ограниченной палитрой (движок рисует их
  чёткими пикселями, NEAREST), спрайт Миры (5 выражений, длинные чёрные волосы) —
  пиксельный, с прозрачным фоном. **АВТОР не показывается** — он только голос
  (по замыслу: «его модель не должно быть видно»).

- **Главное меню**: дрейфующее звёздное поле с падающими звёздами, редкие сердечки,
  «дышащее» свечение названия, посвящение в подвале. После финала — рассветная палитра и пункт «ЕЩЁ РАЗ ♥».
- **Настройки** (всё сохраняется): громкости (общая/музыка/звуки/атмосфера), скорость текста
  (до мгновенной), скорость авто-режима, размер текста, полный экран, отключение тряски/частиц,
  мягкие вспышки, язык (Русский/English).
- **Титры** (минимальные; полные — в Фазе 10) и плавные затемнения между всеми экранами.
- **Шрифты включены**: JetBrains Mono (кириллица) и Press Start 2P (латинские заголовки), оба SIL OFL.

## Архитектура (Фаза 2)

**8 автолоадов** (порядок важен — см. `project.godot`):

```
LocalizationManager → SettingsManager → AudioManager → SaveManager
→ AchievementManager → GalleryManager → DialogueManager → GameManager
```

- **GameManager** — флоу сцен, состояние прохождения, фрагменты сообщения, флаги выборов.
- **DialogueManager** — загрузка JSON-глав, поток шагов, справочники персонажей/выборов.
- **SaveManager** — 5 слотов + autosave + quicksave, PNG-превью, прогресс между запусками.
- **SettingsManager** — звук/текст/дисплей/язык → `user://settings.cfg`.
- **AudioManager** — кроссфейд музыки (fade out → change → fade in), эмбиент, пул SFX, плеер песни.
- **AchievementManager / GalleryManager** — разблокировки (хранятся в `user://progress.json`).
- **LocalizationManager** — `t(key)` для строк UI + двуязычные поля `{"ru","en"}`.

Сцены: `scenes/ui/boot.tscn` (старт) → `scenes/main_menu` → `scenes/visual_novel/vn_stage.tscn`.
VN-сцена уже играет JSON-главы конца в конец (реплики с эффектом печати, выборы,
автоматические шаги, фрагменты, автосейвы) — Фаза 4 нарастит презентацию, не трогая формат данных.

**Пользовательские пути:** всё в `user://` (saves, settings, progress), ассеты — только `res://`. Windows-специфики нет.
